开学到现在第一次正经啃模电。**说实话比想象中难**，不是公式难记，是那种感觉 —— 你以为你懂了，一做题又啥也不会。

## 1. 直流偏置和交流信号

最大的坎是搞清楚这两个东西。书上说叠加，一开始我看那个 Q 点画在曲线上，脑子里全是糊的。

后来 B 站找了个老师讲的，他用了一个比喻：

> 直流偏置就是把秋千推到一个高度先固定住，交流信号是在这个高度附近的小幅摆动。脱离了直流偏置，三极管根本进不了放大区。

这下突然就通了。**分析放大电路必须先算 Q 点**，Q 点不对一切白搭。

## 2. 小信号模型怎么来的

课本上一上来给你一堆 `r_be`、`g_m`、`β`，告诉你这就是 BJT 小信号等效电路。我一开始懵的就是**为什么能这样等效**。

自己推了一遍才发现：本质就是在 Q 点对 i-v 曲线求斜率，把非线性器件在小范围内近似成线性的。工程上常用的"在工作点附近线性化"思想。

这里有个关键的关系式：

```
g_m = I_CQ / V_T
r_be = (β + 1) · V_T / I_EQ ≈ β / g_m
```

其中 `V_T` 是热电压，常温下约 26 mV。这个数字得记死，做题离不开。

## 3. 共射、共集、共基记不住怎么办

我用了个超笨的办法：把三种组态都画了一遍，然后**用一句话总结每种的特征**：

- **共射**：电压增益大、有相位反转、输入输出阻抗中等 → 典型放大级
- **共集（射极跟随器）**：电压增益 ≈ 1、输入阻抗高、输出阻抗低 → 阻抗变换
- **共基**：电压增益大、电流增益 ≈ 1、高频特性好 → 高频或差分尾巴

## 4. 这一周的收获

其实最大的收获不是学了多少公式，是 **知道自己卡在哪** 了。一开始我以为是数学不行，后来发现是物理直觉不够 —— 没办法在脑子里"看见"载流子怎么动。

接下来要硬刚多级放大、负反馈、运放。电赛在 7 月，时间还够，**稳着来**。

> 学不会的时候，多半是基础概念没贴在地上。回去重读绪论章经常管用。
